# v0.5.1

2 November 2026 · **Stable** · Linux x86_64 and Apple Silicon macOS

## Hold for shortcuts

Hold i to peek at a floating shortcut guide over your music. Releasing the key
hides it immediately; losing terminal focus dismisses it too. Key repeats keep
it open. While searching, i still types normally.

The guide uses grouped panels, highlighted keys, a comfortable reading width,
two columns on wide terminals and a scroll indicator. Click a section or press
1–6 to jump there, and scroll with the wheel, arrows or page keys. Every control
remains documented. The music stays visible behind the overlay.

Hold behavior uses the terminal's actual key-release protocol, supported by
Kitty, Ghostty, Foot and other compatible terminals. On terminals without key
releases, ? or F1 toggles the same overlay; there is no guessed release timer.
The terminal runtime now handles enhanced keyboard events, paste and focus.

![Shortcut overlay using generic demo music](https://github.com/wrestle-R/spotify-tui-rdp/raw/v0.5.1/docs/screenshots/shortcuts-overlay.png)

## Better desktop media cards

Linux MPRIS now includes Spotify album artwork and album names alongside track,
artist, duration and progress. The helper keeps metadata across partial snapshots
for the same track, clears it when the track changes and selects the largest
available official Spotify cover image. The bridge exports populated properties
before announcing the player, preventing an empty initial metadata read.

This uses the existing provider metadata, without another Web API scope or
background artwork download in the TUI. The desktop reads mpris:artUrl normally.
