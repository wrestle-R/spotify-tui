# v0.5.3

3 November 2026 · **Stable** · Linux x86_64 and Apple Silicon macOS

## Open your player from desktop media controls

Linux MPRIS now advertises CanRaise and implements Raise. A desktop media card
that supports opening its player can focus Spotify TUI, or reopen it after the
terminal was closed. Opening the UI leaves playback and the queue alone.

The tray's Open action and the new `spotify-tui open` command use the same
launcher. Hyprland and Sway windows are found by the Spotify TUI application
class; X11 uses wmctrl when available. A matching window is focused instead of
opening another terminal. Requests are serialized while a new terminal maps,
including requests from different processes. Focus failures are reported and
do not cause a duplicate window. Both current and older Hyprland dispatch APIs
are supported.

A user desktop entry and icon are registered when the Linux media service starts.
The entry uses the installed current build, so it follows managed updates.
Desktop shells choose which portions of their media card call Raise; playback
buttons and seeking remain separate actions. The terminal choices remain
Kitty, foot, Alacritty, Konsole, GNOME Terminal and xterm. On other Wayland
compositors, a terminal can open but existing-window focus is shell-dependent.

release is gated by native Linux, macOS 15, macOS 26 and website checks.
