# v0.5.2

3 November 2026 · **Stable** · Linux x86_64 and Apple Silicon macOS

## A quick peek at your shortcuts

Hold i for a compact green shortcut overlay; release to return to your music.
Only Playback, Navigation, Search and Editing are shown. The four groups fit
together without scrolling at normal terminal sizes. Bottom keyboard hints and
the extra guide paragraphs are removed. The player buttons remain clickable.
? or F1 can toggle the overlay in terminals without key-release support.

## Faster library navigation

Loaded collections and searches are cached for 15 minutes, preserving the
selected row and scroll position. Switching back uses those rows immediately.
R explicitly refreshes from Spotify. The session cache is bounded to 20 views
and 20,000 retained track rows, and is cleared when the account signs in again.

Large collections load in ordered batches of 50 songs. At most two Spotify
requests run at once, and the existing request cooldown still applies. The first
batch renders while the remaining pages load. Cancellation and view generations
keep old responses out of a newly selected collection. Complete results replace
the disk cache; failed refreshes preserve the prior complete data.

Explore requests only its first 50 fallback songs, so a large liked library no
longer delays its opening. Provider metadata that initially lacks duration is
refreshed locally until it fills in; this does not add Spotify Web API requests.
